## Retained technical vocabulary

- **RF** and **EMI**: normal CEM laboratory vocabulary used in model, role and
  method names.
- **CAN**: the named communication bus; it must not be translated into an
  ambiguous generic expression.
- **DAQ**: retained in acquisition-specific technical definitions where it is
  the established hardware-class term; operator summaries use `acquisition`
  when the acronym is not needed.
- **SCPI** and **VISA**: retained only in communication-profile and provider
  details because they identify concrete instrument-control contracts.
- **JSON**: restricted to raw editors or technical diagnostics; it is absent
  from the normal fleet workflow.
- **Empreinte / checksum**, internal IDs, operation IDs, device IDs and
  correlation IDs: restricted to collapsed `Détails techniques` disclosures.
- **Profil de pilotage**: normal operator title. `Driver` is allowed only inside
  technical provider/profile details where it names an installed software
  component.

## Acceptance gates

- PASS: a generic model and a concrete fleet instance cannot be confused.
- PASS: a migrated instance has an executable reconciliation action.
- PASS: `reserved`, `assigned_to_setup` and `in_test` cannot be invented
  manually.
- PASS: invalid creation combinations are prevented and explained before a
  normal submission.
- PASS: expired calibration is never described as valid.
- PASS: station/location validation is performed in one immediate write
  transaction.
- PASS: an archived current location does not block unrelated identification
  changes.
- PASS: an ineligible material is retained with its reason and next action.
- PASS: the former `Pré-vol` vocabulary is absent from the operator workflow.
- PASS: a secondary-source failure does not hide the primary object.
- PASS: fleet history contains real audit events, not only timestamps.

## Remaining UX debt

- The broad equipment workspace still owns several technical subspaces and
  should be decomposed after the fleet release without changing this workflow.
- Native select controls intentionally show one line; the selected candidate
  summary below them carries the complete readable model-version evidence.
- Authenticated person names, roles and competencies remain future identity and
  authorization work; actor codes are currently mapped to readable labels when
  known.
- The production bundle remains above the advisory 500 kB threshold. This is an
  existing performance advisory, not a functional or accessibility failure.
