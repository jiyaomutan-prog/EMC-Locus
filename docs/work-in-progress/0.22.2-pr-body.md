## Architecture

0.22.2 separates reusable test intent, reusable measurement topology and one
dated execution configuration. Rust core owns typed variables, deterministic
expressions, functional roles, graph validation, regulation, bounded procedure,
classified limits, post-processing contracts and dry-run plan compilation.
The Local Agent owns transactions, optimistic concurrency, canonical checksums,
audit, outbox and planned-preparation integration.

Physical fleet assignments are not duplicated: the dated configuration is
derived from the authoritative 0.22.1 planned-test preparation revision and
pins exact method, topology and station revisions.

spectrum-analyzer categories resolve through aliases without rewriting models.

## Runtime Limits

This release defines, validates, previews and persists contracts. It does not
control instruments, acquire data, execute FFT, apply runtime corrections,
generate final reports, authenticate users or synchronize laboratories. The
642.51 kB frontend main chunk and one high-severity npm dependency advisory are
recorded follow-up debt.
