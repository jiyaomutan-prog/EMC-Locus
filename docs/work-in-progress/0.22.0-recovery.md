## Release objective

Release `0.22.0` establishes a clear laboratory boundary between:

1. a generic **Modèle constructeur**;
2. an **Exemplaire du parc** actually used by the laboratory;
3. the optional **Métrologie du parc** records attached to that item.

The release also introduces an independent laboratory-location registry,
hierarchical catalogue and fleet navigation, physical-item selectors for
station setup and test preparation, operator-oriented French vocabulary, and
isolated panel loading failures.

## Current phase

Checkpoint 5 is implemented and awaiting publication: executable workflows
now resolve authoritative physical assets and stable laboratory locations,
and LAB CONSOLE exposes distinct hierarchical catalogue, fleet, metrology,
station-setup and location workspaces.

`equipment.sqlite/physical_assets` is the only new-write source of truth
for physical assets and `equipment.sqlite/laboratory_locations` is the location
registry. Every successful command executes its conflict checks, write, audit
and sync outbox insertion under one `BEGIN IMMEDIATE` boundary. Metrology keeps
only dossiers and evidence referencing these assets. Its former `instruments`
table is a trigger-protected 0.21.1 archive and is not used by runtime reads.
