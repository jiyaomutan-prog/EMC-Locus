## Release objective

Release `0.22.0` establishes a clear laboratory boundary between:

1. a generic **Modèle constructeur**;
2. an **Exemplaire du parc** actually used by the laboratory;
3. the optional **Métrologie du parc** records attached to that item.

The release also introduces an independent laboratory-location registry,
hierarchical catalogue and fleet navigation, physical-item selectors for
station setup and test preparation, operator-oriented French vocabulary, and
isolated panel loading failures.
